🍽️ API iFood Clone - Spring Boot
Este projeto é uma API RESTful desenvolvida com Spring Boot, inspirada no funcionamento do iFood, com foco em pedidos de delivery, gerenciamento de restaurantes, clientes, produtos e autenticação via JWT.

🔧 Funcionalidades
✅ Cadastro e login de usuários com autenticação JWT

🛍️ CRUD de restaurantes, produtos e pedidos

🧾 Gestão de clientes e endereços

🛡️ Segurança com Spring Security

🔄 DTOs para melhor controle de entrada e saída de dados

🗃️ Banco de dados PostgreSQL com JPA/Hibernate

🧪 Testado com Postman (ou Insomnia)

🛠️ Tecnologias Utilizadas
Java 17

Spring Boot 3

Spring Security + JWT

Spring Data JPA

PostgreSQL

Lombok

Gradle
